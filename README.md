## Proyecto

Hay que desarrollar un **software de aplicación que automatice procesos de negocio para un cliente real**.

- **No se aceptan:** juegos, simuladores, sistemas embebidos ni software utilitario.
- La empresa cliente **no** puede pertenecer a un familiar de algún integrante.
- El sistema debe tener componentes web y móvil, o solo móvil.
- Equipos de **hasta 5 integrantes**, con formulario de aceptación del proyecto.
- El proyecto dura **dos términos** (Ingeniería de Software I y II). La empresa debe contar con la infraestructura necesaria para poner el sistema en operación en IS II.
- El cliente debe comprometerse a asistir a las reuniones agendadas. El proyecto debe estar dentro del área de influencia de Guayaquil.
- Las herramientas de desarrollo se aprenden de forma autónoma, según lo que necesite el cliente.
- **Revisión por sprint:** cada sprint terminado debe incluir el formulario de aceptación firmado por el cliente y el acta de la *sprint review*.
